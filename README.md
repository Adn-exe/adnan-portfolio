# Adnan Portfolio

A premium, high-performance portfolio featuring cinematic animations and a "Magic Bento" tech arsenal.

## ✨ Features

- **Magic Bento Grid**: An interactive, densely packed 3-column grid with a dynamic spotlight effect that flows across card boundaries.
- **Skill Loop**: A smooth, infinitely scrolling marquee of technical skills calibrated at exactly 100px/s.
- **Cinematic Experience**: Zero "pulse" effects for a cleaner, more stable aesthetic.
- **Glassmorphic Design**: Modern UI with subtle blurs, glowing edges, and high-end typography.

## 🚀 Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Build Tool**: [Vite](https://vitejs.dev/)

## 🛠️ Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```
